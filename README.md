# 🧭 Jornada Viagens

Um site moderno e responsivo para uma agência de viagens, desenvolvido com HTML5 e CSS3.

## 📋 Sobre o Projeto

**Jornada Viagens** é uma plataforma digital para uma agência de viagens apaixonada por criar experiências inesquecíveis. O site apresenta pacotes de viagem, destinos populares e informações sobre condições de pagamento, tudo com design responsivo e intuitivo. Este projeto foi desenvolvido juntamente com a plataforma de cursos Alura, como parte do curso da Trilha Front-End

## ✨ Funcionalidades

- **Header Responsivo** - Menu de navegação adaptável para dispositivos móveis e desktop
- **Seção Hero** - Apresentação da agência com mensagem impactante
- **Ofertas Semanais** - Cards interativos com pacotes promocionais
- **Categorias de Busca** - Filtros para:
  - Pacotes Nacionais
  - Pacotes Internacionais
  - Transfer
  - Seguro Viagem
- **Destinos Populares** - Informações detalhadas sobre principais destinos (Tokyo, Osaka)
- **Condições de Pagamento** - Parcelamento em até 12x e descontos especiais
- **Depoimentos** - Seção para feedbacks de clientes

## 🚀 Como Usar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` no seu navegador
3. Navegue pelo site para explorar as diferentes seções

## 💻 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e responsividade

## 📱 Responsividade

O projeto é totalmente responsivo e funciona perfeitamente em:
- Dispositivos móveis (smartphones)
- Tablets

## 🔗 Navegação

O site inclui links para:
- Blog
- Pacotes de viagem
- Página de contato

## 📝 Notas

- Alguns links estão configurados como placeholders (`#`) e podem ser conectados a páginas reais
- O design utiliza uma paleta de cores moderna e profissional
- A navegação móvel usa um menu hambúrguer para melhor experiência
